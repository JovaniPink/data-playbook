# Note title

- **Status:** Draft
- **Created:** YYYY-MM-DD
- **Last verified:** YYYY-MM-DD or not yet verified
- **Owner:** GitHub handle or named maintainer
- **Scope:** Repository, system, dataset, or decision boundary
- **Promotion target:** Research, tested procedure, decision record, reference, or none

## Question

State the concrete question this note is trying to answer.

## Sources

For each source, record its title, stable URL or repository revision, publisher,
retrieval date, and any rights or exact-use limits.

## Evidence

Separate observed facts, repository-derived transformations, tests or
experiments, and interpretation. Include exact commands, revisions, and
environment details when reproducibility matters.

## Analysis

Describe the reasoning, alternatives, uncertainty, and unresolved questions.
Do not present a proposal, green static check, or local result as deployment or
live-system proof.

## Decision or next proof

Record the accepted decision and owner, or name the smallest evidence needed to
advance the note. If another document supersedes this note, link it and change
the status instead of deleting history.
